# ذكرى

_ذاكرة لوكلاء الذكاء · عبر MCP_

عضو ذاكرة لوكلاء الذكاء الاصطناعي. استرجاع طويل المدى ورسم بياني للكيانات يصل إليه أي وكيل عبر MCP — فما تتعلّمه جلسة تعرفه التالية.

[افتح التطبيق](https://app.zekra.dev) · [اقرأ التوثيق](@docs)

- خادم MCP بعيد على mcp.zekra.dev
- دخول OAuth لـ Claude.ai وChatGPT
- Postgres · VectorChord · BM25
- ملاحظات مشتركة بينك وبين وكلائك
- سطر أوامر واحد لـ Claude Code وCodex وGemini وCursor
- اللوحة على app.zekra.dev

## المزايا

### استرجاع هجين لا متجهات فقط

تشابه متجهي وBM25 يُدمجان برتبة متبادلة ثم يُعاد ترتيبهما. الاسم أو العبارة الحرفية يجدها النصف البارع في الأسماء.

### ساخن وبارد كالدماغ

طبقة ساخنة تُجيب بسرعة وطبقة باردة تحفظ كل شيء، وتوحيد محكوم بالأهمية ينقل ما يهم بينهما دون أن تنتبه.

### إعادة توحيد عند الاسترجاع

التذكّر يغيّر الذكرى — الاسترجاع يقوّيها ويتيح تصحيحها بدل ترك معلومة قديمة تُسترجع إلى الأبد.

### أي عميل، بروتوكول واحد

‏Claude Code وسطح المكتب وCodex وGemini CLI وCursor تتصل عبر سطر أوامر zekra. أما Claude.ai وChatGPT فتتصل بالخادم البعيد على mcp.zekra.dev وتسجّل الدخول عبر OAuth — دون أي برنامج محلي.

### كل ذكرى ملاحظة

ما يحفظه الوكيل ملاحظة تستطيع قراءتها ووسمها وربطها وتحريرها من اللوحة — وكل ملاحظة عقدة في رسم كيانات الدماغ.

### أدمغة محدودة الصلاحية وخزنة أسرار

كل دماغ يُمنح لكل وكيل ولكل شخص على حدة برموز محدودة الصلاحية. وأي بيانات اعتماد تُلصق في ذكرى تُنقل إلى خزنة مشفّرة بدل حفظها نصًا.

## حوّل ما يعرفه فريقك إلى عروض وتقارير وصفحات — بالعربية والإنجليزية

_لفريقك_

الذاكرة التي يبنيها وكلاؤك هي ذاكرة فريقك أيضًا. عروض ذكرى تبدأ من ملاحظة أو استعلام استرجاع أو دماغ كامل، وتصوغ عرضًا أو تقريرًا أو صفحة جاهزة للعميل مما يحويه الدماغ فعلًا.

### من الملاحظات والأدمغة

اختر ملاحظات أو استعلامًا أو دماغًا؛ تُبنى المسودة من تلك الذكريات لا من صفحة فارغة.

### عرض أو تقرير أو صفحة

مصدر واحد بثلاثة أشكال: شرائح للعرض، وتقرير للإرسال، وصفحة للنشر.

### بالعربية والإنجليزية

العربية من اليمين إلى اليسار بتخطيط سليم، لا بانعكاس لاحق.

### ‏PDF وWord

صدّر العرض أو التقرير بصيغة PDF أو مستند Word قابل للتحرير.

### روابط مشاركة خاصة

شارك مع العميل برابط؛ الرابط هو المفتاح الوحيد ويمكنك إلغاؤه.

### مملوكة للدماغ

تعيش العروض مع الدماغ الذي خرجت منه، وتحت صلاحيات الوصول نفسها.

## البداية

1. ثبّت سطر الأوامر

   `curl -fsSL https://app.zekra.dev/install.sh | sh`

2. سجّل الدخول برمز من اللوحة

   `zekra auth login --token cbt_...`

3. اربط ذكرى بعميلك

   `zekra mcp:install claude-code --brain my-project`

4. أو أضفه إلى Claude.ai أو ChatGPT

   `https://mcp.zekra.dev`

## لماذا ذكرى؟

أربع طرق يعرف بها الوكيل شيئًا، من الأقصر عمرًا إلى الأطول.

## الحالة
