# Zekra

_AI エージェントのためのメモリー · MCP 対応_

AI エージェントのためのメモリー基盤。長期的な想起とエンティティグラフを、どのエージェントも MCP 経由で利用できます。ひとつのセッションで学んだことを、次のセッションはもう知っています。

[アプリを開く](https://app.zekra.dev) · [ドキュメントを読む](@docs)

- mcp.zekra.dev のリモート MCP
- Claude.ai と ChatGPT 向けの OAuth サインイン
- Postgres · VectorChord · BM25
- あなたとエージェントが共有するノート
- Claude Code、Codex、Gemini、Cursor に対応する 1 つの CLI
- app.zekra.dev のコンソール

## 特長

### ベクトルだけではない、ハイブリッド想起

ベクトル類似度と BM25 を相互順位融合で統合し、さらに再ランクします。名前や正確なフレーズは、名前に強い側の検索が見つけ出します。

### 脳のような、ホットとコールド

海馬のようなホット層が素早く答え、皮質のようなコールド層がすべてを保持します。重要度に応じた統合処理が、気づかないうちに大切なものを両者の間で移し替えます。

### 想起のたびに再統合

思い出すことは、記憶を変えることでもあります。想起によってメモリーが強まり、修正もできるため、古い事実がいつまでも取り出され続けることはありません。

### どのクライアントでも、ひとつのプロトコル

Claude Code と Desktop、Codex、Gemini CLI、Cursor は zekra CLI から接続します。Claude.ai と ChatGPT は mcp.zekra.dev のリモートサーバーに OAuth でサインインして接続でき、ローカルのバイナリは不要です。

### すべてのメモリーがノート

エージェントが記録した内容は、コンソールで読み、タグ付けし、リンクし、編集できるノートになります。すべてのノートは、ブレインのエンティティグラフのノードでもあります。

### スコープ付きブレインとシークレットのボールト

各ブレインは、スコープ付きトークンで、エージェントごと、人ごとにアクセスを付与します。メモリーに貼り付けた認証情報は、テキストのまま保存されず、暗号化されたボールトに移されます。

## チームの知識を、デッキ、レポート、ページに。アラビア語と英語に対応

_チームのために_

エージェントが築くメモリーは、チームのメモリーでもあります。Zekra のプレゼンは、ノート、想起クエリ、ブレイン全体を起点に、ブレインが実際に持つ内容から、顧客向けのデッキ、レポート、ランディングページを下書きします。

### ノートとブレインから

ノート、クエリ、ブレインを選ぶと、白紙からではなく、それらのメモリーをもとに下書きが作られます。

### デッキ、レポート、ページ

ひとつのソースから、3 つの形に。発表するスライド、送るレポート、公開するページです。

### アラビア語と英語

右から左へ書くアラビア語も、後付けの反転ではなく、きちんとレイアウトされます。

### PDF と Word

デッキやレポートを、PDF または編集可能な Word 文書としてエクスポートできます。

### 非公開の共有リンク

顧客にはリンクで共有します。リンクが唯一の鍵で、いつでも取り消せます。

### ブレインが所有

プレゼンは、元のブレインに属し、同じアクセス許可の下で管理されます。

## はじめる

1. CLI をインストールする

   `curl -fsSL https://app.zekra.dev/install.sh | sh`

2. コンソールで発行したトークンでログインする

   `zekra auth login --token cbt_...`

3. Zekra をクライアントに組み込む

   `zekra mcp:install claude-code --brain my-project`

4. または Claude.ai や ChatGPT に追加する

   `https://mcp.zekra.dev`

## なぜ Zekra なのか

エージェントが何かを知る方法は 4 つあります。持続時間の短いものから長いものへ。

## ステータス

公開中です。コンソールは app.zekra.dev、リモート MCP サーバーは mcp.zekra.dev で稼働しており、Postgres、VectorChord、BM25 を使い、埋め込みと再ランクは TEI で処理しています。記録、想起、ノート、エンティティグラフは日々使われています。

## エージェントに、記憶を。

コンソールを開いて、ブレインを作成し、スコープ付きトークンを発行して、Claude Code、Cursor、Claude.ai、ChatGPT、またはあらゆる MCP クライアントを接続しましょう。
